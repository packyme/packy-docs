1. Open CC-Switch to view the home screen:

![](/assets/image/CC-Switch/guide/003.jpg)

2. In the top application switcher, select **Codex**.

![](/assets/image/CC-Switch/guide/012.jpg)

3. Click `+` in the top-right corner and select **PackyCode** from preset providers.

![](/assets/image/CC-Switch/guide/013.jpg)

4. As covered in [Create API Token](/en/docs/register/4-token.html), create a token in the **Codex** group on PackyAPI and copy your API Key.

![](/assets/image/CC-Switch/guide/014.jpg)

5. Paste the copied API Key into the `API Key` field and click **Add** in the lower right.

![](/assets/image/CC-Switch/guide/015.jpg)

6. Return to the provider list, find PackyCode, and click **Enable**. The status will display **In Use**.

![](/assets/image/CC-Switch/guide/016.jpg)

7. Run `codex` in your terminal. When the conversation interface starts and responds properly, configuration is complete.

![](/assets/image/CC-Switch/guide/017.jpg)

To display your consumed and remaining balance directly on the PackyCode card, continue to [Usage Query Setup](/en/docs/ccswitch/4-usage-query.html).
