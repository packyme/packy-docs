CC-Switch can display consumed quota and remaining balance for PackyCode directly inside the interface. Usage queries require your **System Access Token and User ID**, which are distinct from the API Key used for model requests.

1. On the PackyCode provider card, click **Configure Usage Query** on the right side.

![](/assets/image/CC-Switch/guide/018.jpg)

2. Toggle on **Enable Usage Query** and select the preset template `NewAPI`.

![](/assets/image/CC-Switch/guide/019.jpg)

3. Set the Request URL to `https://www.packyapi.ai`. Go to PackyAPI **Personal Settings → Security Settings** to generate a System Access Token; your User ID is displayed at the top of the Personal Settings page.

![](/assets/image/CC-Switch/guide/020.jpg)

4. Enter the System Access Token and User ID into the corresponding fields.

![](/assets/image/CC-Switch/guide/021.jpg)

5. Click **Save Configuration**. When you return to the provider list, you will see your real-time quota status and can refresh it on demand.

![](/assets/image/CC-Switch/guide/022.jpg)
