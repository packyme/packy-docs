## Image Generation with Cherry Studio

1. Refer to [Create API Token](/en/docs/register/4-token.html) to create an API token under the **gemini** group. Once created, click the copy button to copy your API Key to the clipboard.

![](/assets/image/Paint/banana/01.webp)

2. Visit [Cherry Studio](https://www.cherry-ai.com/) to download the application.

3. Launch Cherry Studio and click the Settings icon in the top right.

![](/assets/image/Paint/banana/02.webp)

4. Select `Model Services` on the left and click `Add` at the bottom.

![](/assets/image/Paint/banana/03.webp)

5. In the Add Provider dialog, configure provider name and type as shown:

![](/assets/image/Paint/banana/04.webp)

6. Select the newly added `Packyapi` provider on the left. In the API Key field, paste your `gemini` group API Key from Step 1. Set the API address to `https://cf.api.fan`.

![](/assets/image/Paint/banana/05.webp)

7. Click the `Manage` button below and select our image generation models. PackyAPI includes pre-optimized resolutions and aspect ratios:

![](/assets/image/Paint/banana/06.webp)

8. Once added, the models will appear in your provider list:

![](/assets/image/Paint/banana/07.webp)

9. Click the `Home` button in the top left to return to the main dashboard. Click the settings icon next to your active assistant. Under `Model Settings`, find `Streaming Output` and **make sure to turn it OFF**. Close the settings dialog.

![](/assets/image/Paint/banana/08.webp)

![](/assets/image/Paint/banana/09.webp)

10. In the model selector at the top of the chat view, pick the image generation model you added:

![](/assets/image/Paint/banana/10.webp)

11. Start typing your creative prompts!

![](/assets/image/Paint/banana/11.webp)
